## What's new
- **Unmuffle now updates itself.** When a new version is out, a small banner appears at the top of the window, plus a notification if Unmuffle is in the background. Click **Update** and it downloads, installs and relaunches on its own.
- **Check for Updates…** in the Unmuffle menu, whenever you want to look yourself.
- Updates are signed, and Unmuffle only installs ones signed by us.

> [!NOTE]
> Versions before 1.3 can't update themselves. Download 1.3 once below; from then on Unmuffle keeps itself up to date.

<details>
<summary><b>First time opening Unmuffle?</b></summary>

Unmuffle isn't notarized by Apple, so macOS blocks it the first time. Click **Done**, open **System Settings → Privacy & Security**, and click **Open Anyway** next to Unmuffle. If macOS says the app is damaged, run this in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Unmuffle.app
```

</details>

<details>
<summary><b>For developers</b></summary>

- The GitHub version now runs outside the App Sandbox, so Sparkle can replace the app when it updates. The Mac App Store version is unchanged: sandboxed, and updated by the App Store.
- `scripts/release.sh` builds, signs and adds each release to `appcast.xml`.

</details>
