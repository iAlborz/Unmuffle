## What's new
- Unmuffle is now notarized by Apple, so macOS opens it right away. No more "Apple could not verify" warning.

New in 1.4: **Instant mode**. Drop videos and Unmuffle cleans them up right away, saving each one next to the original as `name-1`. See the [1.4 release](https://github.com/iAlborz/Unmuffle/releases/tag/v1.4).

> [!NOTE]
> Already on 1.3 or later? Unmuffle updates itself: click **Update** in the banner, or choose **Unmuffle → Check for Updates…**.
