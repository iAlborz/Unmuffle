## What's new
- In Japanese and Polish, the mode names at the top of the window are no longer cut off.

New in 1.4: **Instant mode**. Drop videos and Unmuffle cleans them up right away, saving each one next to the original as `name-1`. See the [1.4 release](https://github.com/iAlborz/Unmuffle/releases/tag/v1.4).

> [!NOTE]
> Already on 1.3 or 1.4? Unmuffle updates itself: click **Update** in the banner, or choose **Unmuffle → Check for Updates…**.

<details>
<summary><b>First time opening Unmuffle?</b></summary>

Unmuffle isn't notarized by Apple, so macOS blocks it the first time. Click **Done**, open **System Settings → Privacy & Security**, and click **Open Anyway** next to Unmuffle. If macOS says the app is damaged, run this in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Unmuffle.app
```
